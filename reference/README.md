# Reference material

This folder holds **third-party reference screenshots** used only to understand product
behaviour and UI patterns while building Vaani AI (an original product). They are **not** Vaani
assets and are **not** shipped or redistributed.

Per `CLAUDE.md`: reference material is for understanding patterns only — no proprietary code,
assets, branding, or visual designs are copied into the product.

## Contents (git-ignored binaries — kept local only)
| File | Source | Shows |
| ---- | ------ | ----- |
| `talkpal-progress.png` | app.talkpal.ai/progress | Progress page: daily feedback, stats (total/avg practice time, days studied, score), overall practice-time chart (7/28/all-time), level |
| `talkpal-home-learning-modes.png` | app.talkpal.ai (home) | Home: learning-mode cards (Chat, Roleplays, Word, Call…), explore courses, level, streaks, daily feedback |

The image files are intentionally listed in `.gitignore` so proprietary screenshots are not
committed/pushed. Analysis derived from them lives in `docs/REFERENCE_ANALYSIS.md`.
